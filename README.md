## 📌 Abstract

EHR Vault is a hybrid architecture that combines the decentralized storage power of IPFS with centralized data warehousing via Apache Spark for secure, scalable, and regulatory-compliant Electronic Health Record (EHR) management. It ensures patient data confidentiality, enables predictive healthcare analytics, and supports enterprise-level decision-making.

---

## 🚀 Features

- 🔐 Decentralized EHR data storage with **IPFS**
- 🧊 Centralized data warehousing using **Apache Spark**
- 📊 Real-time analytics and predictive modeling
- 🧮 Data extraction from 50+ MySQL hospital branches
- ✅ HIPAA-compliant architecture with encryption and access control
- 📈 Comparative performance with Spark, Hadoop, EMR & Snowflake

## 🎯 Objectives

1. Develop a secure, decentralized EHR storage framework.
2. Enable enterprise-level predictive analytics and decision support.
3. Ensure compliance with regulatory standards like **HIPAA**.
4. Improve patient care, resource allocation, and healthcare outcomes.
5. Foster interoperability between branches using standardized formats.

## 📊 Results

- 📉 40% reduction in processing time over Hadoop
- 🚀 Real-time data analytics with Spark Streaming
- 🧠 Predictive models for patient admission, resource allocation
- 📈 Supports data scale beyond 100 TB with low latency
